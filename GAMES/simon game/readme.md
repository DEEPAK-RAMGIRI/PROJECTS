<h1 align="center"> SIMON GAME</h1>

### How to Play 🎮
- Click any button to begin the game.
- Watch the sequence of colors the game flashes.
- Repeat the sequence by clicking the color buttons in the correct order.
- Each correct sequence increases the level.
- Game ends if a wrong button is pressed.

### Technologies Used 🛠

- HTML5

- CSS3

- JavaScript (DOM manipulation & event handling)
